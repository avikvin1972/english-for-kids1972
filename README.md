# Связка GitHub Pages + Firebase — инструкция

## Часть 1. Firebase Console (https://console.firebase.google.com)

1. **Создайте проект**: "Add project" → задайте имя (например, `english-for-kids`) → можно отключить Google Analytics, он не нужен → "Create project".
2. **Добавьте веб-приложение**: на странице проекта нажмите иконку `</>` ("Add app" → Web) → задайте имя приложения → **не** подключайте Firebase Hosting (мы используем GitHub Pages) → "Register app".
3. Firebase покажет объект `firebaseConfig` — скопируйте его целиком и вставьте в файл `firebase-config.js` из этого набора вместо плейсхолдеров.
4. **Включите Authentication**: в меню слева → Build → Authentication → "Get started" → вкладка Sign-in method → включите **Anonymous**.
5. **Включите Firestore**: в меню слева → Build → Firestore Database → "Create database" → выберите режим **production** → выберите регион (ближайший к вашим пользователям) → Create.
6. **Загрузите правила безопасности**: Firestore Database → вкладка Rules → вставьте содержимое файла `firestore.rules` из этого набора → Publish.

## Часть 2. GitHub

1. Создайте новый репозиторий (публичный или приватный — Pages работает с обоими на платных планах; на бесплатном для Pages репозиторий должен быть публичным).
2. Загрузите в него все 3 файла из этого набора: `index.html`, `firebase-config.js` (уже с вашими реальными значениями), `firestore.rules` (для истории, сам файл на хостинг не влияет — правила применяются только через консоль Firebase).
3. Включите Pages: Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `root` → Save.
4. Через 1-2 минуты сайт будет доступен по адресу вида `https://<ваш-логин>.github.io/<репозиторий>/`.

## Часть 3. Проверка

Откройте опубликованную страницу и нажмите "Запустить проверку". Если всё настроено верно, вы увидите зелёный блок "Всё работает!" с UID и временем записи. Если ошибка — она укажет, что не так (обычно это неверный конфиг или не опубликованные правила).

После успешной проверки эта связка готова: дальше я буду добавлять сюда реальные приложения по темам грамматики, которые будут писать прогресс ребёнка в `progress/{uid}/...` в Firestore.
